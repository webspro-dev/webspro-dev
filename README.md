Основная задача — не просто написать код, а корректно встроить решение в существующий проект.

При работе учитываю:

* существующую архитектуру проекта;

* производительность;
* совместимость с текущим кодом;
* безопасность;
* возможность дальнейшего сопровождения.

Предпочитаю понятные и поддерживаемые решения без необоснованного усложнения проекта.
